# SIC v0.1 prerelease

This public release presents the Python context-editing Core, official Langflow/Studio integration sources, reproducible research tools and Chinese [preprint v1](paper/sic_paper_zh_v1.md). Zenodo deposition is **pending**; this record contains no assigned DOI.

The `v0.1` tag and attachments may be replaced during prerelease preparation. Source commits and artifact SHA256 manifests identify individual builds. `sic-core` retains package version `0.1.0`; the older Rust `9.0.0-alpha.3` binary and custom WebUI are legacy.

## Included behavior

Independent WB/CB chronological chains, immutable corresponding CBs, recursive N-order editing, persistent operation communication, P/V/I, scoped Editors, scheduling, real peer routes, Socket/board, host permissions and complete-category accounting are available in the Python Core. The optional B `shared_i` layout shares canonical Worker SIC teaching/CB messages and uses later trusted mode/scope; `separate` remains the default. Explicit fallback preserves complete supported inputs.

The publication build passed 273 Core tests with zero failures/errors/skips and 38 integration unit tests. B-specific Core regression and actual loopback SDK request evidence are separately recorded. These numbers do not certify every feature combination or physical cache behavior. New B frontend sources/SDK paths are complete; standing B GUI loading and browser acceptance remain pending.

Real DSH exploratory control g completed three mechanically valid synthetic cases with two exact answers. Separate-layout SIC h completed two valid/exact cases; its third case failed execution and is unscored. Shared-layout i recorded eight SIC-side attempts and three CBs. Its independent wire audit verifies the shared messages/tools, while the task failed on malformed Editor JSON and remains unscored. Failed attempts remain preserved. No fixed-model quality or cost advantage is established; prices are unknown, and DSH display zeros are placeholders.

## Boundaries

Late post-snapshot tool material may enter the fixed CB through a program KEEP supplement; that provenance does not imply the same first-order Editor processed it semantically. Published CBs and operations remain immutable.

Supported API profiles and static inline-media policies are explicit. Unknown carriers/counting policies, auto detail, remote image fetching, audio and video are rejected. Outbound execution uses canonical Chat/LiteLLM; Chat SSE is buffered. Native Responses/Anthropic HTTP proxies and token-by-token forwarding are not included.

Distribution excludes private working manuscripts, raw logs/sessions, credentials, runtime databases, video, corpora and model weights.
