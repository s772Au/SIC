## 共同对象与不可替代关系

以a标识逻辑Agent路线，s标识其内部正在维护的上下文，l标识表示阶数。每个适用的(a,s,l)具有自己的WB形成时序和CB形成时序，同阶`WB_i^(l) ↔ CB_i^(l)`是编辑前后的块对应。未发布工作块的对应状态要清楚。Source片段如何装配成WB及op如何定位片段，是块内来源管理，不代替两条链。

高阶WB引用下阶CB的有序范围，经过真实编辑形成新的高阶CB；各阶保留双链/同阶对应与跨阶成员、范围、次序。高阶产物实际供Worker或Editor继续工作，再可逐阶回原WB。目录、检索和有限摘录是导航/取材手段，不是高阶WB→编辑→CB。实现必须支持一般允许阶次，并以至少三阶的真实运行验证递归，而不是硬编码一个二阶标签。

Worker和多个Editor可共享同阶链和高阶产物，分别保留提示、源解释、模型绑定及活动选择；Editor独有材料也能递归整理。内部升阶/增加Editor不自动增加Agent；从checkpoint另开独立路线才是peer fork。新造而非沿既有链继续的路线另记一个或多个creator。

固定性约束的是已发布对象：CB正文、持久op与对应关系不原地改写。作为高阶WB材料可引用/展开旧CB，在候选中编辑其新表示并发布新的高阶CB，不能把这种合法升阶误禁为“不能编辑CB”。纠正旧信息使用新P/V/I；高阶概括不删除下阶记录。持久记录不等于每个请求必须全量展开所有下阶P。

存储/索引结构、ID布局、共享引用、无损机械编码、分页、模型/程序分工和API拓扑可等价优化。下列输入、关系、真实行为和证据不可省；代理部署可选，适配优先复用成熟实现，Editor不编辑整个原生控制请求。

T-COST使用虚构TEST币种：Worker互斥普通输入60、缓存读40、输出10；高阶Editor普通输入50、输出5；三类单价2/0.1/3。LLM费用应为154+115，程序1×5、存储2×3，总计280。去掉必要usage/价/测量必须变为未知/不完整，不能仍报280或补0。实际provider测试仍以原usage类别及真实价版本重算，不能套这个fixture假价。

共用成本定义以D §3与P §4为准：先冻结同任务、同WB集合、同压缩终点、模型/tokenizer/价版本和等效CB正文/op/索引目标。WB首次读取、同目标生成、Worker首次接入只在相同计费类别下分别抵消；重读、推理/封装、新目标、类别不匹配与迟到program KEEP未由Editor读取的范围，恢复实际差额。程序/存储及全部角色、阶次与peer不漏账。

```text
F = Σ(i=1…N−1)c_i
H = Σ(i=1…N−2)(N−i−1)c_i
C_E,CB-bg = p_h,E(F+H) + (p_u,E−p_h,E)M + C_cache-write
ΔC_total = C_E,CB-bg + R_E − S_W,prefix
         + ΔC_WB-once + ΔC_CB-target + ΔC_Worker-CB-first
         + D_front + ΔC_mix + ΔC_other
C_LLM = Σ实际调用j Σ互斥计费类别c p_jc·t_jc
C_total = C_LLM + C_program + C_storage
```

c_i计该Editor实际编码下CB正文/op/索引，F/H是读取量而非命中结论。A首次冷建/以后命中取M=F、全冷取F+H；B仅在真正共享证据成立时取M=0，一般用实际M。C_cache-write是相对已计基础输入的净调整，不能叠加含基础输入的整份写入价。R_E包含额外轮次的WB重读、完整提示/封装、推理、新输出与调用费；ΔC_mix只计已配对调用的共同教学/注册表增长，不能再计额外轮次已归R_E的提示。S_W,prefix是前缀节省分量，仅在两臂都命中时用Σ_j p_h,W(ℓ_base,j−ℓ_SIC,j)，Worker其他调用/输出变化在ΔC_other逐项恢复；全Worker费用差S_W只作核对，不再重复减。

自然等待不免token费。局部同次覆写且同前缀/位置/长度预算，只令额外前沿破坏D_front为0，不代表整任务0成本。费用接近原机制的条件是净增加与节省相抵，实际可更省或更贵；价值不抵扣账单，未知不填0。ρ_content与ρ_billed分别声明计数器，F+H≈c_avg·N·(N−1)/2不采用正文压缩率偷换实际CB/op/索引量。

T-COST-CONTROL仍保留原c=[10,20,30]、F=30、H=10、p_u=2、p_h=0.1、p_o=3、O_S=5、O_B=8、S_W=40、D=7及ΔC=19，现明确为主式的特例：C_E,CB-bg=61、R_E=0、S_W,prefix=40、ΔC_CB-target=−9、ΔC_other=7，其余项0。它不是通式或实测。T-COST-SHARED-PREFIX另列C01–C10，独立核A冷/热、B理想/部分未命中、含输入写入价、完整净差/未匹配项、提示不双计、未知与跨路线交集；参数和预期见矩阵。

## 共享稳定教学与可信I：横跨角色、递归和总账的统一要求

**目标与证据状态**：required-functional-target; optional prototype existence is not acceptance of all scopes or physical caching。

**公共教学、CB与注册表**：同一Worker SIC适应性教学（包含Editor模式识别/职责/上下文导航）+同一renderer的CB链+同序同构可共同公开的工具注册表；B中CP/WP稳定教学一致，不拼两份全文。

**冻结范围**：Agent/chain、context、level、cut、CB IDs/顺序、完整预算、model/provider/cache namespace、媒体策略、schema/工具版本冻结为同一plan；job/mode/query/时间不进入共同前缀。

**可信I激活与可编辑I隔离**：公共CB之后的宿主激活块标明mode/role、CB边界/此前只读参考、新WB editable scope/assigned units、输出协议与激活工具；独立于模型editable I。

**新WB到新CB的循环**：新WB→有序七操作与PVI候选→程序核scope/授权/物化→append发布新CB→更新I并冻结新cut计划；旧CB不能target，未涉及单元KEEP。

**实际执行与采用权限**：宿主真实actor/chain/mode/role/session/job/assigned units/toolID/current ACL epoch在派发与采用重核；模型pvi.I和旧capability不能授予或恢复权限。

**全部角色、递归和独有上下文**：Worker/多个Editor可用共享或独有N阶context；共享教学不强制同模型/同预算/同CB选择。不同scope如实分开，不为相同字节删材料。

**完整预算、媒体与回退**：完整计入教学/CB/op/索引/tools/协议/I/WB/媒体；不相容时明确不适用并完整回A，或报告预算拒绝；不截断/丢图/丢工具关系。

**逻辑请求与物理缓存证据**：字节序列/工具表/消息分块与位置先比较；provider envelope差异记录；物理cache key、M/usage/写入费用未知保持unknown；逻辑plan/loopback不充当命中证据。

**费用归属**：共同项按同类别配对一次；R_E含额外WB重读/完整提示/推理与新输出；Delta_C_mix只计已配对调用共同教学/注册表增长；自然窗口只影响适用墙钟/前沿项，不免token费。

**两个官方界面**：Langflow与Studio分别实际保存/重载/执行并与同Core对照；展示可信I与editable I、scope、角色/预算/回退和请求首差；各GUI状态单列。

### F04 多个Editor实际分工与合并

**来源**：D §1 一个Agent中的工作、编辑与程序；P §3.1 一个Agent及其内部工作上下文；D §2.3 七类操作与持久操作通信；P §3.3 操作式交付与可回放记录；D §3.2 共享Worker SIC教学与CB前缀、可信I编辑模式；P §4.2 共享SIC适应性教学与CB链，I激活编辑模式。

## 实现与验收组织

先验证双链、同阶对应和普通编辑，再运行真实二阶/三阶生成、共享/独有角色采用和逐阶回溯；随后把工具期编辑、PVI、历史peer与真实宿主贯穿同一工作过程。两官方界面最终必须操作这些真实对象，并与同Core持久事实一致。总账和实验贯穿所有角色/阶次，不在末尾补一份估算代替原记录。

当前源码、运行实例与历史成绩另册列出；没有证据的目标保持未验收，已存在的局部证据保留原范围。实现可以分阶段落地，但任何阶段都不能把尚缺的主机制从此功能目标中删除或改名为已完成的优化。接口契约可以按等价实现另定，不把本文锁在现有operation名称上。
